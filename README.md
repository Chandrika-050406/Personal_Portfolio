# Personal Portfolio Website

## Project Overview
A full-stack personal portfolio website developed using Flask, HTML, CSS, JavaScript, and SQLite.

## Features
- Responsive portfolio website
- About Me section
- Skills section
- Projects section
- Contact form
- SQLite database integration

## Technologies Used
- HTML
- CSS
- JavaScript
- Python Flask
- SQLite

## Project Structure
- Frontend: HTML, CSS, JavaScript
- Backend: Flask
- Database: SQLite
